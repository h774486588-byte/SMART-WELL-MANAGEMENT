# SMART-WELL-MANAGEMENT

## نظام إدارة البئر الارتوازي الذكي

نسخة ويب عربية متجاوبة لإدارة تشغيل البئر الارتوازي: الحجوزات والأدوار، الضخ، العملاء، الديون، التحصيل، الورديات، المصروفات، الديزل، الصيانة والتقارير.

### المزايا الحالية
- لوحة تحكم يومية.
- إدارة حجوزات وأدوار السقي.
- مؤقت بدء/إيقاف الضخ.
- احتساب قيمة الضخ حسب الدقائق.
- البيع بالوقت أو بالنقلة.
- نقدي وآجل مع سقف ائتماني.
- ملفات العملاء والأرصدة.
- كشف الحساب والطباعة إلى PDF من نافذة الطباعة.
- تسجيل التحصيل ومتابعة الديون.
- رسائل واتساب مباشرة من الجهاز.
- الورديات وإغلاق الصندوق مع احتساب العجز أو الزيادة.
- المصروفات والديزل.
- جدولة الصيانة.
- تقارير شهرية مختصرة.
- نسخ احتياطي واستعادة JSON.
- PWA ودعم العمل دون اتصال بعد تحميل التطبيق.
- واجهة RTL ومتجاوبة مع الهاتف والكمبيوتر.

### المعادلة المالية
سعر الدقيقة = سعر الساعة ÷ 60

قيمة عملية الضخ = عدد الدقائق × سعر الدقيقة

### النشر
من GitHub افتح Settings → Pages، ثم اختر Deploy from a branch، وحدد branch: main والمجلد: / (root).

### المرحلة التالية
النسخة الحالية هي أساس الواجهة والتشغيل المحلي. للإطلاق التجاري متعدد الأجهزة نضيف Laravel REST API وPostgreSQL، وتسجيل الدخول والصلاحيات، ومزامنة Offline/Online مركزية، ونسخًا احتياطية خادمية، ثم تطبيق Android مبني بـ Flutter.

لا تضع مفاتيح API أو كلمات المرور داخل ملفات الواجهة الأمامية.
