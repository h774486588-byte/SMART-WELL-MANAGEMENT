# البئر الذكي — SMART WELL

تطبيق Android أصلي لإدارة البئر الارتوازي، وليس موقع ويب.

## الوظائف الحالية
- لوحة تحكم تشغيلية.
- إدارة العملاء والمزارعين.
- الحجوزات وأدوار السقي.
- مؤقت الضخ واحتساب مدة التشغيل.
- تسجيل عمليات الضخ والإيرادات.
- الحسابات والديون والتحصيل.
- كشف حساب العميل.
- المصروفات والديزل.
- الصيانة الدورية.
- التقارير الشهرية.
- الإعدادات والأسعار.
- تصدير نسخة احتياطية للبيانات.
- واجهة عربية RTL متجاوبة.
- تخزين محلي على الجهاز.

## التقنية
- Kotlin
- Android SDK 35
- حد أدنى Android 7.0 (API 24)
- Gradle + Android Gradle Plugin
- لا يعتمد على موقع ويب.

## بناء APK
المستودع يحتوي على GitHub Actions لبناء ملف APK تلقائيًا عند دفع تحديث إلى فرع main. ويمكن فتح المشروع مباشرة في Android Studio ثم تشغيله على جهاز Android أو محاكي.

## المرحلة التالية
إضافة قاعدة بيانات مركزية وLaravel API وPostgreSQL، ثم تسجيل الدخول والصلاحيات والمزامنة بين أجهزة المالك والعامل، مع نسخ احتياطي مركزي وإصدار Release موقّع.
